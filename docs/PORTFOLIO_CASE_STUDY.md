# Portfolio Case Study

## Credit Default Risk Intelligence

An end-to-end machine-learning system built on 30,000 historical credit-card client records.

### What it demonstrates
- data validation
- leakage-safe preprocessing
- stratified splitting
- cross-validation
- multi-model benchmarking
- threshold tuning
- explainability
- responsible-use documentation
- Streamlit deployment interface

### Executed benchmark
The current build selected HistGradientBoosting by cross-validation and produced about 0.780 test ROC-AUC and 0.553 test PR-AUC. The repository workflow regenerates the full metrics and artifacts.
